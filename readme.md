## What this actually is

A local web server that serves a jailbreak payload to the PS4
browser. The PS4 loads the page once, the AppCache stores everything,
and subsequent runs are offline and fast.

## Performance

On my setup:

- **First cold-boot run:** ~5-10 seconds from tap to jailbreak
- **Subsequent runs (kernel already patched):** ~1.53 seconds
- **Reliability:** still low. Some runs need multiple internal retries
  before the primitive lands. I'm working on this in future updates.

This is a **significant improvement** over the original host, which
took 2530 seconds on the same console. But it is not perfect, and it
is not fast enough yet. Treat the numbers above as a best case.

## Requirements

- **A PS4 that can reach your laptop over Wi-Fi.** Both devices must
  be on the **same Wi-Fi network** (same LAN). Different SSIDs or
  different subnets will not work.
- **A laptop / desktop / Raspberry Pi that stays on while you use
  the jailbreak.** Python 3 installed. Any OS.
- **No internet connection required on either device.** The PS4
  never talks to the outside world for this. The whole thing runs on
  your local network.

connection. If your router is online, that's fine  the PS4 just
won't use it.

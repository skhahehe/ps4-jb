## What this actually is

A local web server that serves a jailbreak payload to the PS4
browser. The PS4 loads the page once, the AppCache stores everything,
and subsequent runs are fully offline, utilizing the PS4's internal
HTTP and AppCache storage.

## Performance

On my setup (PS4 Phat 13.02):

- **First cold-boot run:** ~5–6 seconds from tap to jailbreak.
- **Subsequent runs (kernel already patched):** ~1.5 seconds.
- **Reliability:** High on 13.02 (using `KA=16384` and `slots=2000000`).
  If the primitive misses, it automatically retries internally.

This is a massive improvement over the original host (which took 25–30
seconds). The exploit is highly sensitive to the PS4's internal heap layout.

## Setup & Caching (Read Carefully)

The PS4's WebKit browser is notoriously fragile with its AppCache.
If you interrupt the first download, it will cancel the cache and
force you to re-download every time.

### 1. Put both devices on the same Wi-Fi
PS4: Settings → Network → Set Up Internet Connection → pick your
network. You do **not** need internet, just a working LAN connection.

### 2. Start the server on your computer
Open a terminal in this folder and run:
```bash
python3 serve.py
```
The script will print the exact IPs and the port (`8080`).
Copy the Debug URL and open it on the PS4:
`http://<your-ip>:8080/jb.html`

### 3. The "Do Not Touch" First Run (CRITICAL)
When you load the page for the first time (or after changing the
`# rev` line in `cache.appcache`), the PS4 must download ~5 MB of files.

1. Load `http://<your-ip>:8080/jb.html` on the PS4.
2. **DO NOT touch the browser, do not refresh, do not hit back.**
3. Look at your Mac terminal. You will see `📥 [DOWNLOAD]` lines.
4. Wait until the terminal goes completely silent, then **wait an extra 15 seconds**. The PS4 is writing the files to its internal hard drive.
5. Look at the top-right corner of the PS4 screen. The green badge will say:
   `📦 Cache: [version] | 🌐 ONLINE`

### 4. Make it permanent
1. Stop `serve.py` on your Mac (`Ctrl+C`).
2. Close the PS4 browser completely.
3. Open the PS4 browser and tap your bookmark for `http://<your-ip>:8080/jb.html`.
4. The badge will say `🌐 OFFLINE`, and the jailbreak will run at maximum speed.

**If the PS4 ever shows a "connection error"**, it means the AppCache was cleared or corrupted. Start `serve.py` again and repeat Step 3.

## Tuning knobs (for the curious)

These are set inside the JS files. Do not change them unless you
know what you're doing — the exploit's heap layout depends on them.

- `CARRIER_SLOTS` (in `core.js`): Heap carrier buffer size. Default `2000000`. Lower = faster but more likely to fail. Higher = slower but more reliable.
- `KA` (in `jb.js`): Memory arena size. Default `16384`. This halves the execution time of the kernel pointer walk (`passA` / `passB`).
- `N_LEAK` / `SPRAY` (in `jb.js`): Default `65536` / `256` for much faster internal loops.

Both can be overridden at runtime with URL parameters (`?slots=`, `?ka=`) for testing, but the defaults in the file are the values verified to work.
